About

{{ site.tagline }}

Tab Twelve is a documentary-style YouTube channel. Each episode is a deep dive into one subject that deserves more than a headline: internet rabbit holes, unusual people, businesses, subcultures, scandals and ideas worth following further.

The episodes are built to be entertaining first and informative all the way through. They don't pick a side for you. They lay out the strongest version of each case, with the sources on the table, and let you decide.

How this site works

Every video lives on YouTube, and that is where they play. This site is the index: the latest episode up top, the full catalogue, and a page for each episode with the clips, articles and papers it drew on, plus any corrections after the fact.

Sources and corrections

Each episode page lists what was used to make it. If something is wrong, write to {{ site.contact_email }} and it will be checked and, where needed, corrected on the episode page.
