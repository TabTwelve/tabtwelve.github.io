Privacy

Short version: this site doesn't track you.

tabtwelve.com is a static site. It sets no cookies of its own, has no accounts, and runs no advertising.

What is loaded from elsewhere

  • Video thumbnails are loaded from YouTube's image servers (i.ytimg.com). Your browser requests them directly, so YouTube (Google) sees the request the way it would for any image on the web.
  • The typeface is loaded from Google Fonts, which means your browser requests one font file from Google's servers.
  • Videos play on YouTube. Clicking a video takes you to youtube.com, where Google's privacy policy applies.

The site is served by GitHub Pages. Like any web host, GitHub may log the IP address of requests for security and operations. See GitHub's privacy statement.
